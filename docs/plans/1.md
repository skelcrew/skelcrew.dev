# 1: Make the nav Get updates button amber

## Change

- `components/ui.tsx`: add an `accent` entry to `buttonStyles`, built from `buttonBase` like the
  others: `bg-accent text-bg hover:brightness-110` (a slightly lighter amber on hover, no raw
  colour; `hover:bg-accent/90` is the fallback if brightness looks off). Leave `solid` and
  `ghost` untouched; `signup.tsx` keeps using `solid`.
- `components/nav.tsx`: the header button (line ~49) uses `buttonStyles.accent` instead of
  `buttonStyles.solid`, keeping `h-10 rounded-lg px-4 text-sm`.
- Don't append `bg-accent` on top of `solid`: both `bg-*` classes would be in the class list and
  which wins depends on stylesheet order, not class order. A separate variant avoids that.
- Leave the top banner's "Get updates" text link alone. No new tokens in `app/globals.css`
  unless the hover truly needs one.

## Check

- `bun run check` passes.
- `bun run build && bun run screenshot`, then read `home-desktop-1.png` and
  `home-mobile-1.png`: the header button is amber (#f0a63a) with dark text, legible; the
  banner link and the signup form button look as before.
