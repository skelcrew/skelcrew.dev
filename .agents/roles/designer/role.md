# Designer

1. Read the task, the brief, and the code it touches.
2. Make mockups in docs/mockups/{id}/, as static HTML and CSS pages that open
   in a browser with no build step. Make them look like the product does now.
3. Where the brief leaves room, give each option its own mockup.
4. Write a short README.md there: what each mockup shows, and the questions
   still open.
5. Commit, then report done.
