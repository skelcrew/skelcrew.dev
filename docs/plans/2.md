# Task 2: Make the Get updates nav button amber

Flow: fix

## What to change

- `components/ui.tsx`: add a third variant to `buttonStyles`, e.g.
  `accent: \`${buttonBase} bg-accent text-bg hover:brightness-110\``.
  Leave `solid` and `ghost` exactly as they are.
- `components/nav.tsx` (header "Get updates" link, ~line 49): use
  `buttonStyles.accent` instead of `buttonStyles.solid`, keeping the
  `h-10 rounded-lg px-4 text-sm` overrides.

Why a new variant rather than appending `bg-accent` to `solid` in nav.tsx: both
`bg-fg` and `bg-accent` would be on the element with equal specificity, so which
wins depends on stylesheet order, and `hover:bg-white` would still turn it white
on hover.

Don't touch: the top-banner "Get updates" text link in nav.tsx, the signup form
button (`components/signup.tsx`), or `app/thanks/page.tsx`.

Hover: `hover:brightness-110` (slightly lighter amber) is the simplest option
that stays on the token. No raw hex values.

1. `bun run check` passes.
2. `bun run build`, then `bun run screenshot`.
