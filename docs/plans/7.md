# 7: Make the nav "Get updates" button amber

## Change

- `components/ui.tsx`: add a third variant next to `solid` and `ghost`:
  `accent: \`${buttonBase} bg-accent text-bg hover:brightness-110\``.
  `hover:brightness-110` gives the slightly lighter amber on hover without a raw colour or a
  new token. Leave `solid` and `ghost` as they are.
- `components/nav.tsx`: the header link to `/#updates` uses `buttonStyles.accent` instead of
  `buttonStyles.solid`; keep its `h-10 rounded-lg px-4 text-sm` overrides.

Why a new variant rather than appending `bg-accent text-bg` to `solid` in nav.tsx: `bg-fg` and
`bg-accent` (and the two `hover:bg-*`) would both be on the element, and which wins depends on
Tailwind's stylesheet order, not class order.

Do not touch: `buttonStyles.solid`, the submit button in `components/signup.tsx`, the
"Get updates" text link in the top banner of `nav.tsx`, `app/globals.css`.

## How to tell it works

- `bun run check` passes.
- `bun run build`, then `bun run screenshot`. In `screenshots/home-desktop-1.png` and
  `home-mobile-1.png` the header button is amber with dark (`text-bg`) text that reads clearly;
  the banner link is still an underlined plain link; the signup submit button (further down the
  page slices) is still off-white.
- `git diff` touches only `components/ui.tsx` and `components/nav.tsx` (plus this brief).
