# 14: Make the nav "Get updates" button amber

  for the shape, but override its colours on this element only: amber background, dark text
  (`text-bg`), lighter amber on hover. Tailwind v4 merges by class order, so to be safe build
  the class from `buttonBase`-equivalent pieces or add a new `buttonStyles.amber` variant in
