# 17: Make the header "Get updates" button amber

## What to change

The header's "Get updates" link in `components/nav.tsx` (~line 49) uses `buttonStyles.solid`
(`bg-fg text-bg hover:bg-white`). Make it amber, using the existing `accent` token
(`--color-accent: #f0a63a` in `app/globals.css`), which is already the site's amber. Don't add
raw `amber-*` colours: AGENTS.md says to use tokens.

Don't just add `bg-accent` to the existing `buttonStyles.solid` classes. In Tailwind, the order of
rules in the stylesheet decides which class wins, not the order in `className`, so `bg-fg` and
`bg-accent` would conflict and the result is unpredictable.

Instead, add a third variant to `buttonStyles` in `components/ui.tsx` and leave `solid` and `ghost`
exactly as they are:

```ts
accent: `${buttonBase} bg-accent text-bg hover:brightness-110`,
```

Then in `nav.tsx`, swap `buttonStyles.solid` for `buttonStyles.accent` on that one link. Keep its
size overrides (`h-10 rounded-lg px-4 text-sm`). Dark `text-bg` on #f0a63a has strong contrast.

Leave the banner text link ("Get updates", line ~19) and the signup form's "Notify me" button
alone.

## How to tell it works

- `bun run check` passes (lint, typecheck, build).
- `bun run build && bun run screenshot`, then read `home-desktop-1.png` and `home-mobile-1.png`.
  The header button should be amber with dark, readable text. The signup "Notify me" button
  should still be the off-white solid style, and the banner link unchanged.
- `git diff` touches only `components/nav.tsx` (one className) and `components/ui.tsx` (one new
  `accent` line).
- Hover: the button brightens and lifts slightly (from `buttonBase`). Check in `bun run dev` or
  on the Vercel preview.
