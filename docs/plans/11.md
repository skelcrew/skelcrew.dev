# 11: Make the nav "Get updates" button amber

## Change

- `components/ui.tsx`: add a third variant to `buttonStyles`, built on `buttonBase` like the others:
  `accent: \`${buttonBase} bg-accent text-bg hover:brightness-110\``.
  Leave `solid` and `ghost` as they are.
- `components/nav.tsx` (~line 49): swap `buttonStyles.solid` for `buttonStyles.accent` on the header
  "Get updates" link. Keep the `h-10 rounded-lg px-4 text-sm` overrides.

Why a new variant instead of tacking `bg-accent` onto `solid`: the element would carry both
`bg-fg` and `bg-accent`, and which one wins depends on stylesheet order, not class order.

Hover uses `brightness-110` so it stays on the `accent` token with no raw hex. If it looks
washed out in the screenshot, `hover:bg-accent/90` (slightly darker over the dark nav) is the fallback.

Out of scope: the banner "Get updates" text link, `components/signup.tsx` (still `solid`),
`app/thanks/page.tsx`, the token values in `app/globals.css`.
