# 12: Make the nav "Get updates" button amber

## Change
- `components/nav.tsx:49`, the header "Get updates" link, uses `buttonStyles.solid`
  (`bg-fg text-bg hover:bg-white`). Make it amber with the `accent` token.
- Don't just append `bg-accent` to the solid classes: the button would carry both `bg-fg` and
  `bg-accent` (and both hover colours), and which one wins depends on stylesheet order, not
  class order. Add a third variant to `buttonStyles` in `components/ui.tsx` instead, for example
  `accent: \`${buttonBase} bg-accent text-bg hover:brightness-110\`` (a slightly lighter hover;
  `hover:bg-accent/90` is fine if that looks better on the dark header). Use it in the nav:
  `${buttonStyles.accent} h-10 rounded-lg px-4 text-sm`.
- Leave `buttonStyles.solid` unchanged (signup uses it), and leave the top banner's
  "Get updates" text link alone. No raw colours.

## Check

- `bun run build && bun run screenshot`, then read `screenshots/home-desktop-1.png` and
  `screenshots/home-mobile-1.png`: the header button is amber with dark, readable text, and
  the signup button further down is still off-white.
