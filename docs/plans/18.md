# 18: Make the get updates button green

## What
The "Get updates" button is the solid button in the sticky header, `components/nav.tsx:49`
(`buttonStyles.solid`: light `bg-fg` with dark text). Make it green.

## How
- In `components/nav.tsx`, give that one link green classes instead of `buttonStyles.solid`:
  keep `buttonBase` behaviour (use `buttonStyles.solid`'s shape), but colour it with the existing
  `ok` token: `bg-ok text-bg hover:bg-ok/85` (or similar). No raw hex; `--color-ok` (#7bc77e)
  is already the site's green in `app/globals.css`.
  Simplest clean route: add a `green` variant to `buttonStyles` in `components/ui.tsx`
  (`${buttonBase} bg-ok text-bg hover:...`) and use it in the nav.
- Leave the other buttons alone: the "Notify me" / signup submit buttons and the text link
  "Get updates" in the top announcement bar are not this button.

## Check
- `bun run check` passes.
- `bun run build && bun run screenshot`; in `home-desktop-1.png` and `home-mobile-1.png` the
  header "Get updates" button is green with dark, readable text; nothing else changed.
