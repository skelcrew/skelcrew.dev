# 16: Make the Get updates nav button amber

## What to change

- `components/ui.tsx`: add a third variant to `buttonStyles`, e.g.
  `amber: \`${buttonBase} bg-accent text-bg hover:bg-accent-2\``. Leave `solid` and `ghost`
  untouched (`solid` is also used by the signup form in `components/signup.tsx`).
  Don't try to override `solid` by appending `bg-accent` in nav.tsx: there is no
  tailwind-merge, so two `bg-*` classes fight by stylesheet order, not class order.
- `app/globals.css`: `--color-accent` (#f0a63a) is already the site's amber, so use it as the
  background. Add one token for the hover shade, e.g. `--color-accent-2: #f5b95e` (a little
  lighter, matching how `solid` lightens to white on hover), next to `--color-accent`.
  Dark text is `text-bg` (#0e0e0d) — no new token needed.
- `components/nav.tsx` line ~49: switch the header "Get updates" link from
  `buttonStyles.solid` to `buttonStyles.amber`, keeping `h-10 rounded-lg px-4 text-sm`.
  The small "Get updates" text link in the top banner stays as it is.

## How to tell it works

- `bun run check` passes.
- `bun run build`, then `bun run screenshot`; read `screenshots/home-desktop-1.png` and
  `screenshots/home-mobile-1.png`: the header button is amber with dark, readable text on
  the dark header; the signup button lower on the page is still the light `solid` style.
- `grep -n buttonStyles.solid` still shows the signup usage unchanged.
